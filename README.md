# Senkron

## Türkçe

Bu depo, Senkron ile dağıtılan açık kaynak bileşenlerinin kaynak arşivleri, ilgili yamalar, derleme bilgileri ve lisans bildirimleri için hazırlanmıştır.

Senkron’un kendisine ait kapalı kaynak kodu bu depoya dahil değildir. Her üçüncü taraf bileşeni kendi lisansına tabidir.

Kaynak paketleri, karşılık geldikleri Senkron sürümüyle eşleştirilip doğrulandıktan sonra bu deponun Releases bölümünde yayımlanacaktır. İlk kaynak paketi ve doğrulama özeti henüz yayımlanmamıştır; bu sayfanın oluşturulması kaynak setinin tamamlandığı veya uygulamanın yayıma hazır olduğu anlamına gelmez.

## English

This repository is intended to provide source archives, relevant patches, build information and license notices for open-source components distributed with Senkron.

Senkron’s own proprietary source code is not included. Each third-party component remains subject to its own license.

Source packages will be published under Releases after verification and matching to the corresponding Senkron version. The first source package and verification summary have not yet been published. Creating this page does not establish that the source set is complete or that the application is ready for release.
